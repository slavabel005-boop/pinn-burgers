# PINN для уравнения Бюргерса (PyTorch) — прототип

Учебный прототип: физически информированная нейросеть (PINN), написанная на PyTorch без специальных библиотек, для вязкого уравнения Бюргерса:

u_t + u·u_x = ν·u_xx,  ν = 0.01/π

- Область: x ∈ [−1, 1], t ∈ [0, 1]
- Начальное условие: u(x, 0) = −sin(πx)
- Граничные условия: u(−1, t) = u(1, t) = 0

## Метод (как в коде `day20.py`)
- Сеть u_θ(x, t): 2 скрытых слоя по 32 нейрона, tanh.
- Функция потерь = средний квадрат невязки уравнения в 1000 случайных точках + штраф за начальное условие (100 точек) + штраф за граничные условия (100 точек).
- Производные u_t, u_x, u_xx — через torch.autograd (create_graph=True для второй производной).
- Оптимизатор Adam, 20 000 шагов, seed 0.

## Ограничения (честно)
- Решение **не сравнено** с точным решением (Коул–Хопф / эталонные данные Raissi et al.). Значение функции потерь на точках обучения — не мера точности решения.
- Известный дефект: точки границы построены так, что условие на x = −1 проверяется только при t ∈ [0, 0.5), а на x = +1 — только при t ∈ [0.5, 1]. Нужно задать по 100 точек по t на каждой границе.

## Следующие шаги
1. Исправить точки границы.
2. Посчитать относительную ошибку (relative L2) против точного решения на независимой сетке (x, t).
3. Сравнить с классическим конечно-разностным решением.
